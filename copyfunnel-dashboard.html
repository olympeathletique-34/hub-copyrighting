Aperçu
📖 Guide rapide

1. Créer un projet
Cliquez "Nouveau projet", donnez-lui un nom et un prix.


2. Uploader les pages HTML
Glissez vos fichiers HTML dans la zone d'upload. Upload multiple accepté.


3. Réordonner le tunnel
Glissez-déposez les pages pour définir l'ordre du tunnel.


4. Configurer le paiement & email
Onglet "Configuration" → renseignez Stripe, PayPal, Brevo.


5. Ajouter les produits digitaux
Onglet "Produits" → ajoutez vos fichiers avec leur URL WordPress.


6. Générer le tunnel
Cliquez "⚡ Générer" → les fichiers HTML sont modifiés automatiquement (paiement, email, produits injectés) et téléchargeables.

📊 Résultats A/B testing
🏆 Le gagnant est la variante avec le meilleur taux CTA (clics sur le bouton d'achat ÷ visites).
Les stats se mettent à jour en temps réel à chaque visite.
